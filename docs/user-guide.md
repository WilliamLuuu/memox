# memoX 使用文档

本文档面向使用者，说明各页面能做什么，以及**导入/导出的具体文件格式、目录结构和字段含义**。实现细节以当前代码为准（`app/src/main/java`）。

---

## 1. 首页

| 区域 | 行为 |
| --- | --- |
| 左上角搜索 | 展开/收起搜索框，输入即过滤标题与正文 |
| 筛选按钮 | 日期范围、标签、文件夹三个维度组合过滤；可一键清除 |
| 排序按钮 | 按创建时间/修改时间/标题/颜色、升降序切换，全部列表页共用 |
| 视图切换 | 列表 / 双列（网格） |
| 下拉 | 触发 WebDAV / OneDrive 双向同步 |
| 右下角 FAB | 新建笔记；列表下滑后该位置改为“回到顶部”按钮，回到顶部后自动收起 |
| 右上角 | 同步状态“灵动岛” + 头像菜单（设置、关于等） |

笔记卡片展示：标题、正文摘要、创建/修改时间、提醒 chip、文件夹、标签、锁定图标。锁定笔记只显示标题与锁图标。

## 2. 编辑器

- **标题 / 正文**：正文支持可交互清单。
- **标签栏**：点击已有标签进入标签列表；没有标签时显示“添加标签”，点击后手动输入新标签，回车即创建并绑定。
- **文件夹**：为笔记选择唯一文件夹。
- **颜色**：卡片背景色。
- **置顶 / 锁定 / 归档**：通过顶部菜单或长按多选操作。
- **附件**：图片、文件、录音，插入后写入应用私有媒体目录。
- **提醒**：设置一次或重复提醒（分钟/小时/天/周/月/年）。
- **Markdown**：顶部格式菜单可在“富文本 / Markdown”之间切换（新建笔记可选，已有笔记也可切换）；Markdown 模式下工具栏提供粗体、斜体、删除线、标题、列表、引用、代码、链接等快捷插入；“预览”按钮即时渲染正文。
- **撤销 / 重做**：编辑历史按操作回退。只回退内容时不会改变“修改时间”，因此不会把笔记顶到列表最前。
- **自动保存**：退出或切后台时提交；无内容变化的保存不会刷新修改时间。

## 3. 标签 / 文件夹 / 提醒

- 三个页面右下角均有 **+**：
  - 标签页：新建标签。
  - 文件夹页：新建文件夹。
  - 提醒页：先选择一条笔记，再进入提醒编辑。
- 提醒页顶部有“即将到来 / 过期”chip 过滤；“+”与列表项均可进入提醒编辑。
- 提醒页菜单“添加到日历”会把选中的提醒时间写入系统日历（通过 `ACTION_INSERT` 调用日历应用，**不需要**申请日历读写权限）。

## 4. 同步

- WebDAV：服务器地址、用户名、密码；支持双向同步、手动上传/下载。
- OneDrive：OAuth 登录后同步。
- 同步内容：笔记、标签、文件夹、提醒、附件、标签/文件夹隐藏状态。
- 冲突：以 UUID + 版本号判定，冲突时生成“冲突副本”，不覆盖原笔记。

## 5. 导出

设置 → 备份 → **导出备份**，先选择格式：

1. `memoX 完整备份（ZIP）`：可恢复的完整快照。
2. `Joplin JEX`：可导入 Joplin 的交换格式。

文件名默认：`memoX_Backup_yyyy-MM-dd_HH-mm.zip`（JEX 为同名 `.jex`），空格统一替换为下划线。

### 5.1 memoX 完整备份（ZIP）

ZIP 内是**数据库文件 + 附件目录**的原始结构：

```text
memoX_Backup_2025-01-31_12-00.zip
├── MemoXDatabase            # Room/SQLite 数据库（未加密，或 AES 加密）
├── Images/                  # 笔记内图片，文件名与数据库中的 localName 一致
│   ├── 1730000000000.jpg
│   └── ...
├── Files/                   # 普通文件附件
│   └── 1730000000123.pdf
└── Audios/                  # 录音附件
    └── 1730000000456.m4a
```

- 导出时可设置密码。设置密码后 ZIP 使用 **AES** 加密（Zip4j），不设密码则为普通 ZIP。
- 附件按原始文件名写入；数据库中的 `BaseNote.images/files/audios` 保存 `localName`，恢复时按名称重新关联。
- 导出会先复制数据库再打包，不会写坏正在使用的库；打包完成后校验 ZIP 可读，失败会自动重试一次。
- **恢复**：设置 → 备份 → 导入备份，选择该 ZIP。恢复是**整体替换**当前数据库与附件（不是合并）。若 ZIP 有密码，会先提示输入。
- 兼容旧版 Notally/NotallyX 备份：导入时会读取旧列、缺失列按默认值处理。

### 5.2 Joplin JEX

JEX 本质是 ZIP，每条笔记一个 Markdown 文件，附件以资源文件平铺：

```text
memoX_Backup_2025-01-31_12-00.jex
├── 0f3c2a1e-...-9a1b.md        # 笔记，文件名是笔记 UUID
├── 0f3c2a1e-...-9a1b0000.png   # 该笔记引用的资源：<uuid去横线><4位序号>.<扩展名>
├── 0f3c2a1e-...-9a1b0001.pdf
└── ...
```

笔记文件内容：

```markdown
---
title: 笔记标题
created_time: 2025-01-31T04:00:00Z
updated_time: 2025-01-31T04:05:00Z
tags: [工作, 待办]
---

正文（Markdown）。
图片引用写作 :/0f3c2a1e...9a1b0000，Joplin 导入时按资源 ID 还原。
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `title` | 标题，换行替换为空格 |
| `created_time` | 创建时间，UTC，`yyyy-MM-dd'T'HH:mm:ss'Z'` |
| `updated_time` | 修改时间，同上 |
| `tags` | 标签数组，逗号分隔，无标签时省略 |
| 正文 | Markdown 源文；富文本笔记导出时由 spans 一次性转换为 Markdown |
| 资源 | 图片/文件/录音按 `<noteUuid 去横线><序号hex>.<ext>` 命名，正文中的原文件名替换为 `:/<id>` |

限制：

- **内容加密（`NoteProtection.ENCRYPTED`）的笔记会被跳过**，导出结束提示“导出 N 条，跳过 M 条加密笔记”。原因：导出明文会泄露内容，导出密文其他客户端无法读取。
- 旧式“锁定”但未加密的笔记正常导出。
- 导出不会修改原笔记。

### 5.3 单条/多条笔记导出

长按选择笔记 → 导出，可选格式：

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| 纯文本 | `.txt` | 标题 + 正文，丢失样式 |
| Markdown | `.md` | 保留标题、列表、粗体等；图片引用为原文件名 |
| HTML | `.html` | 自带基础样式，可直接浏览器打开 |
| JSON | `.json` | 结构化字段（含 spans、items、附件引用） |
| PDF | `.pdf` | 通过系统打印服务生成 |

## 6. 导入

设置 → 备份 → 导入，支持的来源：

| 来源 | 输入 | 行为 |
| --- | --- | --- |
| memoX / Notally 备份 | `.zip` | 整体恢复数据库与附件 |
| Notally XML | `.xml` | 读取旧版 XML 备份并合并 |
| Joplin | `.jex` | 解析 front matter + 资源，标签自动去重 |
| Google Keep | Takeout `.zip` | 仅解析 Keep 数据 |
| Quillpad | 备份文件 | 标题/正文/清单一对一映射 |
| Evernote | `.enex` | 解析笔记与资源 |
| 纯文本 / JSON | `.txt` / `.json` | 按行或字段生成笔记 |

导入来源选择错误时会提示“无效的备份文件”，不会写坏现有数据库。

## 7. 设置分组

设置首页是入口，点进去后**每个条目只属于一个分组**，不会再出现同一项在多个页面重复显示：

| 分组 | 条目 |
| --- | --- |
| **显示** | 笔记视图、主题、主题色、日期与时间格式、文字大小、Markdown 在列表中渲染 |
| **编辑与保存** | 保存策略、链接卡片、插入时压缩图片、压缩已有图片 |
| **列表与整理** | 起始页、回收站保留天数（多久后永久删除）、最大标签数、概览中隐藏标签 |
| **同步** | WebDAV、OneDrive、备份密码 |
| **数据与隐私** | 数据存储位置、安全标志、空闲自动保存、导入/导出设置、重置设置、清除数据 |
| **关于** | 版本、作者、第三方许可 |

实现上，`SectionAppearanceContent` 的每一行、分组标题和分隔线都带 `cat:display` / `cat:editing` / `cat:lists` 标签，`applyAppearanceCategory()` 只显示当前分组，未打标签的视图不参与展示。历史遗留的排序行（已由首页排序按钮统一控制）已从布局和观察者中删除。

> 根因备注：此前三个分组共用同一个 `SectionAppearanceContent`，只用一个 `displayOnly/listOnly` 硬编码列表做隐藏，动态添加的行（主题色、Markdown 列表渲染）和分组标题没有纳入，导致“压缩已有图片”“多久后永久删除”以及“显示/行为”标题在多个页面重复出现。

## 8. 安全与权限

- 应用不收集个人信息，无广告。
- 联网权限只用于 WebDAV / OneDrive 同步。
- 锁定笔记通过生物识别或系统 PIN 解锁；**锁定本身不等于加密**。需要防止明文落盘时使用“内容加密”保护（加密笔记导出 JEX 会被跳过）。
- 日历：仅通过系统 `ACTION_INSERT` 写入事件，不申请 `READ_CALENDAR/WRITE_CALENDAR`。

## 9. 已知限制

- 恢复完整备份是覆盖式，恢复前建议先导出当前数据。
- JEX 不包含文件夹层级与提醒，只保留标题、时间、标签、正文和资源。
- Markdown 渲染不支持远程图片，图片语法按 alt 文本展示。
- 双列模式下卡片较窄，锁定笔记只显示锁图标与标题。
